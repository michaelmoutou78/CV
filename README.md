# CV GitHub Pages — Michaël David Moutou

1. Créez un dépôt GitHub, par exemple `cv-michael-moutou`.
2. Ajoutez `index.html`.
3. Ajoutez votre CV PDF dans le même dossier et renommez-le `CV_Michael_Moutou.pdf`.
4. Dans GitHub : **Settings > Pages**.
5. Choisissez **Deploy from a branch**, puis `main` et `/root`.
6. Enregistrez.

Le site est responsive et dispose d'une feuille de style d'impression.
